# Button

Commonly used operating buttons: a button triggers an **action** (save, submit, delete). If clicking it navigates
to another page, use a [link button](#link-button).

**Component:** RSuite 6.2.4 `Button`, `IconButton`, `ButtonGroup` and `ButtonToolbar`, re-exported by `@mgs/ui` ·
[RSuite reference](https://rsuitejs.com/components/button)

## Usage

```tsx
import { Button, IconButton, ButtonGroup, ButtonToolbar } from '@mgs/ui';
import '@mgs/ui/styles.css'; // once, in your app entry
```

## Examples

### Basic

<Canvas of={ButtonStories.Basic} sourceState="shown" />

`type` defaults to `"button"`, so a Button never submits a form by accident. Use `type="submit"` for a form's main
action. All native button attributes work (`name`, `value`, `form`, `aria-*`, `data-*`, `ref`).

### Appearance

<Canvas of={ButtonStories.Appearance} sourceState="shown" />

| `appearance`        | Use it for                                                   | Avoid                               |
| ------------------- | ------------------------------------------------------------ | ----------------------------------- |
| `default` (default) | Normal actions: _Cancel_, _Export_, _Edit_                   | The main call to action             |
| `primary`           | The single most important action in a view: _Save_, _Create_ | More than one per section           |
| `ghost`             | Secondary actions that need an outline, on busy backgrounds  | Main actions                        |
| `subtle`            | Low-emphasis actions: toolbars, table rows                   | Anything that must be noticed       |
| `link`              | Actions that should look like inline text links              | Real navigation: use `href` instead |

### Colors

<Canvas of={ButtonStories.Colors} sourceState="shown" />

`color`: `red | orange | yellow | green | cyan | blue | violet`. Use `color="red"` with `appearance="primary"` for
destructive actions (_Delete_); the MGS theme makes that red meet contrast requirements.

⚠️ **Contrast:** with white text only `red` (MGS theme) and `violet` meet WCAG AA (4.5:1). RSuite's other palettes
fail: blue 3.1, green 2.8, orange 2.4, cyan 2.3, yellow 1.8. The Accessibility panel flags these.

### Sizes

<Canvas of={ButtonStories.Sizes} sourceState="shown" />

`size`: `lg | md` (default) `| sm | xs`. Use `md` in forms and dialogs, `sm` / `xs` in dense tables and toolbars.
Match the size of the inputs next to the button. Inside a `ButtonGroup`, set `size` on the group.

### Loading

<Canvas of={ButtonStories.Loading} sourceState="shown" />

Shows a centered spinner; **the button keeps its width** and blocks **mouse** clicks.

⚠️ Enter/Space still activate a focused loading button, and RSuite doesn't set `aria-busy`. Guard the handler
(`if (saving) return;`) and pass `aria-busy={saving}` as shown. Don't use `disabled` for loading: a disabled button
loses keyboard focus.

### Disabled

<Canvas of={ButtonStories.Disabled} sourceState="shown" />

Uses the native `disabled` attribute: the button can't be focused or clicked. Users can't discover _why_ a button is
disabled, so prefer keeping it enabled and explaining what's missing (for example, validate the form on submit).

### Active

<Canvas of={ButtonStories.Active} sourceState="shown" />

`active` shows a button as the current selection. `toggleable` switches `active` on each click and calls
`onToggle(active, event)`.

⚠️ RSuite doesn't set `aria-pressed`. For toggle buttons, control `active` yourself and pass `aria-pressed={active}`.

### Block / Full Width

<Canvas of={ButtonStories.BlockFullWidth} sourceState="shown" />

`block` stretches the button to its container's width, e.g. for stacked actions on mobile. `ButtonGroup` also
accepts `block`.

### With Icons

<Canvas of={ButtonStories.WithIcons} sourceState="shown" />

`startIcon` / `endIcon`, with icons from `@rsuite/icons`. Put leading icons at the start and direction arrows at the
end. Icons are decorative; the label names the button.

### IconButton

<Canvas of={ButtonStories.IconButtons} sourceState="shown" />

⚠️ **An icon-only button must have an `aria-label`** describing the action (_"Delete row"_, not _"Trash"_). RSuite's
types don't require it; the accessibility tests on these stories check it. Use icon-only buttons only for
universally understood icons.

### ButtonGroup

<Canvas of={ButtonStories.ButtonGroups} sourceState="shown" />

Joins related buttons (alignment, view switchers). `size` and `disabled` apply to every button in it. It has
`role="group"`; add an `aria-label`.

### ButtonToolbar

<Canvas of={ButtonStories.ButtonToolbars} sourceState="shown" />

Lays out buttons and groups in a row with consistent spacing (it's an RSuite `Stack`, so `spacing`, `wrap` etc.
work). It has `role="toolbar"`; add an `aria-label`. Focus moves with Tab; there is no arrow-key navigation.

### Link Button

<Canvas of={ButtonStories.LinkButton} sourceState="shown" />

`href` renders a real `<a>` styled as a button, so middle-click and "open in new tab" work. For client-side routing
use `as`: `<Button as={Link} to="/projects">`. A disabled link button leaves the tab order. Never wrap a `<Button>`
in an `<a>`, or navigate with `onClick`.

## Accessibility

<Canvas of={ButtonStories.Accessibility} sourceState="shown" />

| Key               | Action                                   |
| ----------------- | ---------------------------------------- |
| `Tab` / `⇧ Tab`   | Move focus to the next / previous button |
| `Enter` / `Space` | Activate the focused button              |

- Renders a native `<button>` (or `<a>` with `href`), so keyboard, forms and screen readers work out of the box.
- The focus ring shows for keyboard focus only and uses `outline`, so it stays visible in Windows High Contrast
  mode. The MGS theme makes it fully opaque (RSuite's default is 25% transparent).
- The MGS brand blue meets WCAG AA with white text (5.2:1); RSuite's default blue doesn't (3:1).
- Known gaps (see above): loading doesn't block the keyboard or set `aria-busy`; toggle buttons need `aria-pressed`;
  icon-only buttons need `aria-label`. The ripple ignores "reduce motion"; turn it off with
  `<CustomProvider disableRipple>` or `ripple={false}`.

## Props

### `<Button>`

| Property   | Type `(Default)`                                                           | Description                                          |
| ---------- | -------------------------------------------------------------------------- | ---------------------------------------------------- |
| active     | boolean                                                                    | Show the button as the current selection             |
| appearance | `'default' \| 'primary' \| 'link' \| 'subtle' \| 'ghost'` `('default')`    | Visual style                                         |
| as         | ElementType                                                                | Render as another element or component (e.g. `Link`) |
| block      | boolean                                                                    | Full width of the container                          |
| children   | ReactNode                                                                  | Label                                                |
| color      | `'red' \| 'orange' \| 'yellow' \| 'green' \| 'cyan' \| 'blue' \| 'violet'` | Colour palette                                       |
| disabled   | boolean                                                                    | Native disabled                                      |
| endIcon    | ReactNode                                                                  | Icon after the label                                 |
| href       | string                                                                     | Render an `<a>` styled as a button                   |
| loading    | boolean                                                                    | Spinner; blocks mouse clicks                         |
| onToggle   | `(active: boolean, event) => void`                                         | Called when a `toggleable` button changes            |
| ripple     | boolean `(true)`                                                           | Click ripple effect                                  |
| size       | `'lg' \| 'md' \| 'sm' \| 'xs'` `('md')`                                    | Button size                                          |
| startIcon  | ReactNode                                                                  | Icon before the label                                |
| target     | string                                                                     | Link target (with `href`)                            |
| toggleable | boolean                                                                    | Toggle `active` on each click                        |
| type       | `'button' \| 'submit' \| 'reset'` `('button')`                             | Native button type                                   |

### `<IconButton>`

Extends `<Button>`.

| Property  | Type `(Default)`               | Description                         |
| --------- | ------------------------------ | ----------------------------------- |
| circle    | boolean                        | Round button                        |
| icon      | ReactElement                   | The icon                            |
| placement | `'start' \| 'end'` `('start')` | Icon position when there is a label |

### `<ButtonGroup>`

| Property  | Type `(Default)`               | Description                          |
| --------- | ------------------------------ | ------------------------------------ |
| block     | boolean                        | Full width                           |
| disabled  | boolean                        | Disable every button in the group    |
| divided   | boolean                        | Dividing lines between buttons       |
| justified | boolean                        | Equal-width buttons across the width |
| size      | `'lg' \| 'md' \| 'sm' \| 'xs'` | Size of every button in the group    |
| vertical  | boolean                        | Stack buttons vertically             |

### `<ButtonToolbar>`

Accepts `Stack` props such as `spacing` and `wrap`, plus `role` (default `'toolbar'`).

All components also accept `className`, `style` and native attributes.

## Customizing

`@mgs/ui/styles.css` already contains the MGS theme. To customize further, override the `--rs-*` CSS variables in
your app's stylesheet, never `.rs-btn` class selectors. For example, the theme sets:

```css
:root {
  --rs-primary-500: #2563eb; /* primary background */
  --rs-primary-600: #1d4ed8; /* hover */
  --rs-primary-700: #1e40af; /* pressed */
  --rs-focus-ring-color: var(--rs-primary-500);
}
```
