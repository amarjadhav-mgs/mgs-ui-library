# InputGroup

Combines an [Input](?path=/docs/components-input--docs) with text, icons or buttons: a currency sign, a domain, a
search icon, a Search or Clear button.

**Component:** RSuite 6.2.4 `InputGroup`, re-exported by `@mgs/ui` until its MGS API is built (phase 1 of the
implementation plan) · [RSuite reference](https://rsuitejs.com/components/input-group)

## Usage

```tsx
import { Input, InputGroup } from '@mgs/ui';

<label htmlFor="amount">Amount</label>
<InputGroup>
  <InputGroup.Addon>₹</InputGroup.Addon>
  <Input id="amount" />
</InputGroup>
```

Put an MGS [Input](?path=/docs/components-input--docs) inside. ⚠️ The group doesn't label the input: give the input
its own `<label htmlFor>` or `aria-label`.

## Accessibility

<Canvas of={InputGroupStories.Accessibility} sourceState="shown" />

- The input keeps its own label; add-on text isn't part of it. If the add-on matters (a currency), say it in the
  label: "Amount (₹)".
- Buttons in the group are in the Tab order after the input.
- The group's border meets 3:1 contrast in every theme, and turns to the error colour when the input has
  `aria-invalid="true"`.

## Props

| Property | Type `(Default)`                | Description                                       |
| -------- | ------------------------------- | ------------------------------------------------- |
| disabled | boolean                         | Disable everything in the group                   |
| inside   | boolean                         | Put add-ons inside the input's border             |
| size     | `'sm' \| 'md' \| 'lg'` `('md')` | Size of everything in the group, including inputs |

Parts: `InputGroup.Addon` (text or an icon) and `InputGroup.Button` (a button). All accept `className` and `style`.

## Customizing

Colours come from the MGS tokens (`--mgs-color-border-control`, `--mgs-color-border-error`). Override tokens in your
app's stylesheet, never `.rs-*` classes or `--rs-*` variables.
