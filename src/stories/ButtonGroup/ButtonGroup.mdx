# ButtonGroup and ButtonToolbar

`ButtonGroup` joins related buttons (alignment, view switchers). `ButtonToolbar` lays out buttons and groups in a row
with even spacing. Both work with the MGS [Button](?path=/docs/components-button--docs) and
[IconButton](?path=/docs/components-iconbutton--docs).

**Component:** RSuite 6.2.4 `ButtonGroup` and `ButtonToolbar`, re-exported by `@mgs/ui` ·
[RSuite reference](https://rsuitejs.com/components/button-group)

## Usage

```tsx
import { Button, ButtonGroup, ButtonToolbar } from '@mgs/ui';
```

## Accessibility

<Canvas of={ButtonGroupStories.Accessibility} sourceState="shown" />

- `ButtonGroup` has `role="group"` and `ButtonToolbar` has `role="toolbar"`. **Add an `aria-label`** to each, so screen
  readers announce their purpose.
- Focus moves between buttons with Tab; there is no arrow-key navigation. Buttons in a disabled group are skipped.

## Props

### `<ButtonGroup>`

| Property  | Type `(Default)`       | Description                          |
| --------- | ---------------------- | ------------------------------------ |
| block     | boolean                | Full width                           |
| disabled  | boolean                | Disable every button in the group    |
| divided   | boolean                | Dividing lines between buttons       |
| justified | boolean                | Equal-width buttons across the width |
| size      | `'sm' \| 'md' \| 'lg'` | Size of every button in the group    |
| vertical  | boolean                | Stack buttons vertically             |

### `<ButtonToolbar>`

Accepts `Stack` props such as `spacing` and `wrap`, plus `role` (default `'toolbar'`).
