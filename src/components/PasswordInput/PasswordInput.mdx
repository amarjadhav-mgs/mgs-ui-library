# PasswordInput

A password field with a **Show password** button, so users can check what they typed. It works with password
managers and browsers' autofill, and everything a form needs (label, errors, `required`) goes to the `<input>`.

**Component:** MGS-owned, built by MGS on `Input` and `InputGroup` · Related:
[Input](?path=/docs/components-input--docs)

## When to use

- For any password or secret the user types: sign-in, sign-up, change password, API keys.
- **Not for PINs and one-time codes.** A dedicated code input will cover those.

## Import

```tsx
import { PasswordInput } from '@mgs/ui';
```

## Usage

```tsx
<label htmlFor="password">Password</label>
<PasswordInput id="password" autoComplete="current-password" />
```

Label it like an [Input](?path=/docs/components-input--docs). Set `autoComplete` to `new-password` on sign-up and
change-password forms, so password managers suggest a strong password instead of filling the old one.

### Common usage

- **Sign in:** email `Input` with `autoComplete="username"`, then `PasswordInput` with `current-password`.
- **Sign up and change password:** `new-password`, with the password rules as text linked by `aria-describedby`.
- **Confirm password:** a second `PasswordInput` with `new-password`; compare the two on submit.

## Do and don't

| Do                                                        | Don't                                              |
| --------------------------------------------------------- | -------------------------------------------------- |
| Set `autoComplete` (`current-password` or `new-password`) | Turn autocomplete off: it blocks password managers |
| Show the password rules before the user types             | Reveal the rules only after an error               |
| Let users paste passwords                                 | Block paste, which breaks password managers        |
| Use one label, "Password"                                 | Put the rules in the placeholder                   |

## Accessibility

<Canvas of={PasswordInputStories.Accessibility} sourceState="shown" />

| Key               | Action                                                |
| ----------------- | ----------------------------------------------------- |
| `Tab` / `⇧ Tab`   | Move between the field and the Show password button   |
| `Space` / `Enter` | On the button: show or hide the password; focus stays |
| `Enter`           | In the field: submits the form                        |

- The Show password button is in the Tab order. Its name stays "Show password", and `aria-pressed` tells screen
  readers whether the password is shown.
- Label, `aria-describedby`, `aria-invalid`, `required` and `ref` go to the `<input>`, unlike RSuite's PasswordInput,
  which put them on a wrapper.
- ⚠️ The button's name is in English for every locale, as in MGS's supported locales today.

## API

<Controls of={PasswordInputStories.Playground} />

Every native `<input>` attribute also works on the `<input>` (`id`, `name`, `required`, `minLength`, `aria-*`,
`onFocus`, `onBlur`, …), and `ref` points at the `<input>`. `className` and `style` go to the outer wrapper, for
layout.
